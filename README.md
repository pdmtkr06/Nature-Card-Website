# Lago di Braies – Nature & Lake Card

## 📌 Project Description

This is a simple beginner-friendly website project created using **HTML and CSS**.

The project displays a beautiful information card about **Lago di Braies**, a famous lake destination. The card contains an image, category buttons, a title, description, and a **Read More** button.

## 🛠️ Technologies Used

* HTML5
* CSS3

## ✨ Features

* Simple and clean card design
* Lake image
* Nature and Lake category buttons
* Hover effect on buttons
* Rounded corners
* Box shadow
* Responsive basic layout
* Read More button

## 📁 Project Structure

```text
Lago-di-Braies/
│
├── index.html
├── image.png
└── README.md
```

## ▶️ How to Run

1. Download or clone the project.
2. Keep `index.html` and `image.png` in the same folder.
3. Open `index.html` in any web browser.
4. The Lago di Braies card will appear on the screen.

## 🎯 Learning Purpose

This project helps beginners understand:

* HTML structure
* CSS styling
* Classes
* Buttons
* Images
* Borders and border-radius
* Box shadows
* Hover effects
* Basic webpage layout
